## Goal
A question box at the top of 邮件:
- the conversation lives only in React state, and `historyFor` sends the last 6 answered
  turns;
- the send button is disabled while a question is pending, so a double click does not
  make two billed calls;
- the answer is plain text, never HTML;
- cited mails are shown as normal mail lines that open;
- the Hub's 502/503 sentence is shown inline;
- 「还有 N 封没整理」 is shown when needed;
- 清空对话 clears the conversation.

## Acceptance (runnable)
- `pnpm run test`: `historyFor` keeps only answered turns, at most 6, each cut to 1000
  characters; `askMail` sends the question, history and zone, and a 503 detail comes back
  in `ApiError`; before anything is typed, the box renders with a disabled send button.
- `uv run python scripts/verify/web.py` exits 0. On 邮件 it asks a question, sees the
  answer and the cited mails, opens a cited mail, and screenshots `18-mail-chat`. A
  `[fake:500]` question shows "请再问一次", and that 502 is the only console error
  allowed.
- `uv run python -m tools.check` exits 0.
