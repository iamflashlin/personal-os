## Goal
The user, 2026-11-22: GPA is theirs to handle; the system should own **homework
submission**. Reminders only inside the Hub for now (no Windows notifications). ADR 0044.

- One 作业 page: 缺交, 24 小时内要交, 本周要交, 最近交了 (with the time Canvas recorded).
- 去提交 on each item: the desktop agent opens that assignment's Canvas page (whitelisted
  `open_url`, verified by window title). The user writes and submits the work themself.
- 我交了，查一下: asks Canvas to sync now; an item counts as submitted only when Canvas
  records it (never from a click or a model).
- Reminder: 今日 shows the most urgent unsubmitted homework due within 24 h at the top,
  and the sidebar's 作业 shows how many need attention.

Not in scope: writing or submitting work (CIS is human-led), grades, Windows notifications.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_homework.py -q`:
  - the board groups Canvas assignments into missing / due within 24 h / due within 7
    days / submitted in the last 7 days, sorted by due time; excused work and copies of
    handed-in work (combined classes) are left out, whether missing or not due yet;
  - the reminder is the nearest unsubmitted item due within 24 h, or none;
  - open with no agent connected is 503 and stores nothing; with an agent it dispatches
    one `open_url` for the assignment's own URL, at most once per Idempotency-Key;
  - open for an unknown item, another owner's item or a non-assignment is 404; an item
    without a Canvas link is 422;
  - check requests a sync for each Canvas integration and returns the job ids; without
    Canvas it is 409.
- `uv run python scripts/verify/homework.py` exits 0: a real Hub and a real agent on this
  PC; 去提交 opens a served page whose title is checked, and the run reports succeeded.
- `uv run python scripts/verify/web.py` exits 0, including the 作业 page and the 今日
  reminder (screenshots in `.evidence/T-0066/`).
- `uv run python -m tools.check` exits 0.
