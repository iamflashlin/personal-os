## Goal
Seen on the live 今日 page (2026-11-12): "邮件里要你做的" still listed seven homework
reminders due 11/9, and mail the user had marked 已处理 on the 邮件 page still showed on
今日, both as needing action and as unread. T-0038 fixed the 邮件 page only.
- A mail counted as 已处理 (by hand or by an enabled rule, `triage.handled_ids`) is not
  listed as needing action, not listed as unread and not counted in the headline.
- A mail whose AI-read deadline date is before the user's today is not listed as needing
  action (a deadline today still is). A mail without a deadline is unchanged.
No contract change; 邮件 is unchanged.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_today.py -q`:
  - deadline yesterday leaves, today stays, none stays;
  - marking a mail 已处理 removes it from the actions, the unread list and the count, and
    marking it 未处理 again brings it back.
- On a copy of the live DB: the expired 11/9 reminders are gone from the actions and the
  unread count leaves out handled mail (`.evidence/T-0056/live-copy.txt`, local only).
