## Goal
The user wants the fewest words for the most value: "对我没有任何效率提升的价值的东西我不要". The
user specified:
- **List:** each mail shows an AI title that says only what it is about and its deadline
  (≤ 20 characters), plus an importance mark. It replaces the original subject.
- **Opened mail:** the distilled useful points first (3-5 short lines), then the
  original text.
- **Low-value mail** (ads, newsletters, plain notices that need nothing) is collapsed into
  one line, 「已收起 N 封没有价值的邮件」, which expands on click.
- **A new 邮件 page** holds this list. The 连接 page keeps only connections and points to
  it. The chat window (T-0027) will live here too.

Prompt v2 returns `title`, `importance`, `low_value`, `points`, `action_needed`, `action`,
`deadline_text` and `deadline_date`. Mail summarised with v1 is redone once with v2,
about US$0.04 for the ~60 existing mails. After that, every mail is summarised once.

## Out of scope
- Summarising all history (T-0026). Chat and batch rules (T-0027).
- Any change to the mailbox (it stays read-only, ADR 0022).

  - low-value mail is left out of 今日's 未读邮件 list, with its count in
    `low_value_mail`;

  - opening a mail shows points before the original text.
