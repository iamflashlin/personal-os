## Goal
- Each triage group lists its own mails as normal mail lines that open (points, original,
  已处理 toggle): the first 3, then 「展开全部 N 封」.
- Original text is shown as paragraphs. Web addresses become short safe links
  (「打开链接 · domain」), and mail is never rendered as HTML.
- New mail keeps its line breaks: block tags end lines, spaces collapse within a line, and
  at most one blank line is kept. Mail already stored was flattened and is not re-read, so
  normally there is no re-summary cost; it is split at its ___ / --- rules instead. Stored
  mail is re-read (and re-summarised once, within the monthly cap) only if the server
  renumbers its UIDs, or an unfinished history re-read is still running. The live cursor
  shows backfill_done = true.

## Acceptance (runnable)
- `pnpm run test`: `paragraphs` splits flattened mail at rules and keeps real paragraphs;
  links are safe and short, and HTML is shown as text.
- `uv run pytest tests/hub/test_email.py -q`: plain and HTML mail keep their paragraphs, and
  scripts are dropped.
- `uv run python scripts/verify/web.py` exits 0, including: a mail inside a group opens with
  its points and original text.
- `uv run python -m tools.check` exits 0.
