## Goal
VISION direction 1 (个人第二大脑), made usable: in the PC browser the user can search
their memories in Chinese or English, add one, correct one, confirm an AI guess, and delete
one, seeing where each memory came from and how sure it is. Uses only the existing
`/memories` API (T-0005); no Hub change, no new dependency.

## Context / inputs
`packages/contracts/memory.py`, `apps/hub/memory/api.py`, the existing page from T-0004
(`apps/web`), ADR 0011 (the UI is a thin client), ADR 0013 (search rules).

## Out of scope
Phone layout (S4), memories created by a model (S5), linking memories to tasks, editing
kind/expiry from the UI, bulk import.

## Acceptance (runnable)
- `pnpm run test` covers the new API client calls (search query string, PATCH with version,
  confirm, delete) and `pnpm run typecheck` passes
- The page has a 任务 / 记忆 switch; the memory view lists memories, searches as you submit,
  adds a memory with kind and sensitivity, shows provenance and confidence, confirms an
  `ai_inferred` memory, corrects a body inline (version-checked; a 409 reloads), and deletes
  only after a second click; secret bodies are masked until "显示" is pressed
- `uv run python scripts/verify/web.py` (extended) drives Edge: adds a memory through the
  form, finds it with a two-character Chinese search, confirms an AI guess seeded over HTTP,
  corrects a memory and finds it under the new wording, deletes it after confirming; the Hub
  API agrees after each step; screenshots of the memory view; no console errors; exits 0
- `uv run python -m tools.check` exits 0
