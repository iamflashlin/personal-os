## Goal
V0.1 S1 part 3: all Hub data can leave this machine and come back intact — the
foundation of "migrate to a Mac/server without losing memory" (HANDOFF §2, §4.7).

## Context / inputs
HANDOFF §4.7: export package = SQLite online backup + one JSONL per table + file dir +
`manifest.json` (schema version, row counts, SHA-256 per file). Import restores into an
**empty** directory and runs migrations.

## Out of scope
restic / offsite backup and scheduled drills (S7); encryption.

## Acceptance (runnable)
- `uv run python -m tools.pos export --data-dir <d> --out <zip>` and `... import --in <zip> --data-dir <new>` work; import refuses a non-empty target dir (exit ≠ 0, clear message)
- `uv run pytest tests/hub -q` passes, including the round-trip test: seed goals/projects/tasks/workspaces/audit → export → import into a new temp dir → start Hub → every row equal (ids, timestamps, versions) and `/health` ok
- Import rejects a package whose checksum does not match (tampered file test)
- Import of a package with an older schema version runs migrations to head (test with a fixture package)
- `uv run python scripts/verify/hub.py roundtrip` does export→import→start against real processes and temp dirs; exits 0
- `uv run python -m tools.check` exits 0 on windows-latest and ubuntu-latest
