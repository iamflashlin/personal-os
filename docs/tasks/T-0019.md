## Goal
The first slice of the "one connected day" (ADR 0012): open the site and see, on one page,
what is due today and in the next three days, what is missing or overdue, today's events,
unread mail from the last 24 hours, new course announcements and tasks in progress. It is
computed on request from what the connectors already synced, so it fills as soon as the
user connects Canvas and mail, and it never writes anything.

## Out of scope
- Model-written summaries, notifications or pop-up cards at set times (later, after the
  user's daily routine is known).
- Changing anything in Canvas, the mailbox or the calendar.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_today.py -q`: assignments due today, in 1-3 days and
  missing land in the right lists in the user's time zone (late-evening deadlines do not
  slip a day); all-day events stay on their own day; graded or submitted work is badged;
  only unread mail from the last 24 hours is listed, newest first, at most 8; overdue
  open tasks are missing, done tasks never appear; a failed source is listed under
  problems; an empty Hub gives an empty view with a plain headline; another owner's data
  never appears.
- `uv run python scripts/verify/hub.py today` exits 0 against the real Hub with a fake
  calendar feed, fake Canvas and fake IMAP server.
- `uv run python scripts/verify/web.py` exits 0; 今日 is the first tab and shows the
  headline and sections; `uv run python -m tools.check` exits 0.
