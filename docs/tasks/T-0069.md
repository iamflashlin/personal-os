## Goal
14-system list #14 (成长可视化), on what the user cares about now: handing homework in.
At the top of 作业: this week's counts in one line (按时 · 迟交 · 缺交 · 还没交), and a
small stacked bar per week for the last 4 weeks, so the trend shows at a glance.

Counted by due week (local Monday to Sunday), computed from synced Canvas assignments:
handed in on time / late (Canvas's own flag), missing (Canvas's flag), open (not due
yet). Excused work and combined-class copies are left out as on the board; past work
with no submission that Canvas does not mark missing (paper, in class) is not counted.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_homework.py -q`: weeks count on time, late, missing and
  open by due week in the given zone, skip excused, uncounted paper work and anything
  outside the window; the endpoint takes the browser's zone, rejects an unknown zone
  and more than 12 weeks.
- `pnpm run test`: the week line and labels.
- `uv run python scripts/verify/web.py` exits 0: 作业 shows four weeks and counts the
  missing lab (screenshot).
- `uv run python -m tools.check` exits 0.
