## Goal
14-system list #3 (时间管理) and #13 (主动管家). 今日 said what to do (先做这个) but not
when: today's classes, the homework blocks set aside with 排时间, deadlines and free time
were split between 日程 and 今日's 今日日程 (calendar events only).

今天的安排 replaces 今日日程 with one list from the schedule's agenda for today (the
browser's day): all-day entries first, then everything in time order with free time
between; what is on now is marked 现在 and the next thing 下一项 (never a free slot);
what is over fades. Homework blocks say 写作业, Canvas deadlines name their course.
No model, no new endpoint (reuses `GET /schedule`).

## Acceptance (runnable)
- `pnpm run test`: `planRows` orders all-day first then by time with free time, marks
  now / next (not free time), names homework blocks and Canvas courses, passes what is
  over and a deadline once gone.
- `uv run python scripts/verify/web.py` exits 0: a class running now shows on 今日 as
  现在 and 上课; 今日 fits a phone (screenshot `36-today-plan.png`).
- `uv run python -m tools.check` exits 0.
