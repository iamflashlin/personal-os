## Goal
14-system list #3 (自动排优先级) and #13 (主动管家), and the standing "one answer first"
rule: 今日 should open with one thing to do now, not a list to read.

先做这个, at the top of 今日, computed from the homework board (no model):
1. homework due within 24 h and not handed in → 「还剩 3 小时：Journal 4（ENGL 1000）还没交」 + 去提交;
2. else homework Canvas marks missing → 「缺交：…，已过 2 天」 + 去提交;
3. else homework due this week with no time set aside → 「还剩 2 天：…，还没排时间」 + 排时间;
4. else nothing: the 开始学习 card below is the answer.
It replaces the T-0066 reminder line (same first case, now with its button).

## Acceptance (runnable)
- `pnpm run test`: `firstThing` picks in that order, skips homework already planned, and
  is null with no board or no work.
- `uv run python scripts/verify/web.py` exits 0: on 今日 the missing lab is 先做这个 with
  去提交; the routed 24-hour case still shows the reminder text and 去作业页 (screenshots).
- `uv run python -m tools.check` exits 0.
