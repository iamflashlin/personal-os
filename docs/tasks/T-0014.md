## Goal
Windows Python has no time-zone database, so ADR 0019 kept `TZID` times raw and flagged.
The user approved adding the `tzdata` package. With it, an event such as
`DTSTART;TZID=America/Los_Angeles:20261113T150000` (De Anza College is in California)
becomes an exact UTC time on this PC, including across daylight-saving changes.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_ics.py -q` passes, including: a Pacific time in November
  (PST) and one in July (PDT) give the right UTC times; an unknown zone is still flagged.
- `uv run python -m tools.check` exits 0 (Windows locally, both CI platforms).

.evidence/T-0014/: pytest.log, check.log, summary.md

## Errors & lessons

- With tzdata installed, `ZoneInfo("America")` opens a directory and raises
  PermissionError (Windows) or IsADirectoryError (Linux), which the parser did not catch:
  one odd line would have failed the whole feed. Found in review before merge; OSError is
  now caught and folder names are flagged (`test_odd_tzids_never_break_the_feed`).
