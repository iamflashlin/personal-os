## Goal
The user (2026-11-12): the UI is not simple, convenient or clear enough; every element must
earn its place and nothing is said twice. The 成绩 page showed everything about every
course at once (about 2600 px on the live Hub). Now:
- the GPA is one large number with one short caption;
- each course is one line: short name (MATH 1A), letter, percent, and the one sentence that
  matters (what the remaining work must average to keep the letter), plus 缺交 only when
  there is any;
- a click opens that course: targets, how the grade is made up, work to hand in, recent
  scores, the reminders, the rules card and the materials. Nothing in there repeats the line;
- how the numbers are computed is one closed line at the bottom of the page.
No Hub call changes.

## Acceptance (runnable)
- `pnpm run test`: short course names (MATH D001A -> MATH 1A, CIS D022A -> CIS 22A,
  ECON C2002 -> ECON 2002); the sentence for keeping the letter; materials by module.

  percent; opening it shows the missing lab, the notes, the units and the rules card, which
  can be confirmed; a syllabus-computed course hides Canvas's group table.
- On the live Hub (real data, local screenshot): the page fits one screen at 1440x900 with
  all four courses closed.
- `uv run python -m tools.check` exits 0.
