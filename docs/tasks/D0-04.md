## Goal
Turn the task loop into reusable skills so every session writes cards, evidence and
verification the same way.

## Context / inputs
HANDOFF §6.2, §7.1, §7.3, §7.4; ADR 0002 rules (own windows only, content-control-only
screenshots); `/pstack:create-verification-skill`.

## Out of scope
verify-hub / verify-desktop-agent *implementations* (they need S1/S2 code); these skills
describe the procedure and point at scripts that later cards create.

## Acceptance (runnable)
- `.claude/skills/{task-card,evidence,verify-hub,verify-desktop-agent}/SKILL.md` exist with valid frontmatter (`name`, `description`)
- In a fresh session, `/task-card` produces a card that passes `uv run python -m tools.taskcard docs/tasks/<new>.md` (frontmatter + required sections check; added in this card under `tools/`)
- `scripts/verify/_common.py` provides `evidence_dir(task_id)` and `capture_control(control, path)` (captures one UIA content control, never a window rectangle — ADR 0002); `uv run pytest tests/verify -q` passes
- `.github/pull_request_template.md` has sections: what, acceptance table, evidence summary, user decisions, 这次学到什么, review steps
- `uv run python -m tools.check` exits 0
