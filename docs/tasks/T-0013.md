## Goal
Make the integrations foundation usable without the API: on the PC, in the browser, the
user can paste a calendar subscription link (for example Canvas's Calendar Feed), see it
sync in the background, see what is coming up in the next 14 days, sync now, see errors,
and disconnect. The link is never shown again after it is entered.

## Out of scope
- Email and the Canvas REST API, a phone layout, editing an existing connection.

## Acceptance (runnable)
- `pnpm run typecheck` and `pnpm run test` pass; the client tests cover: the link goes
  only to `PUT /credentials/...` and never into the integration body; a failed create
  removes the credential again; disconnect deletes the integration, then its credential
  (a missing credential is fine); the items window is sent as ISO times.
- `uv run python scripts/verify/web.py` exits 0 in Microsoft Edge with a real Hub, a real
  local feed and a throwaway Credential Manager entry:
  - add a feed through the form; the background sync fills "接下来 14 天";
  - the token is never in the page; the link field is empty after connecting;
  - after the feed changes, 立即同步 shows the new title;
  - a failing feed shows 出错 with its reason;
  - 删除 needs two clicks and removes the integration, its items and the credential
    (gone from Credential Manager);
  - the existing task and memory flows still pass; no console errors.
- `uv run python -m tools.check` exits 0.
