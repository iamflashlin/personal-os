## Goal
VISION direction 1 (个人第二大脑): the Hub remembers the user's preferences, facts,
decisions and experiences, records where each came from and how sure it is, lets the
user correct or confirm it, forgets what has expired, and finds it again by text in
Chinese or English. This is the first link of 记忆 → 规划 → 启动 → 执行 → 成长; every
later direction reads and writes it. It is in both HANDOFF (§4.3 Memory, S7) and the
ADR 0012 proposal (memory moves earlier), so it does not depend on the open decisions.

## Context / inputs
HANDOFF §4.3: memory rows add `provenance` (raw / user_confirmed / ai_inferred /
verified), `confidence`, `expires_at`, `sensitivity`; kinds preference / fact / decision /
experience; FTS5 search (ADR 0006). A spike on 2026-11-10 showed that the default
`unicode61` tokenizer cannot find a Chinese word inside a sentence, while `trigram`
finds substrings of 3+ characters; shorter terms need a substring match.

## Out of scope
Vector search (P1), automatic extraction of memories by a model (S5), a web UI for
memories, Memory ↔ Task links, sharing between owners.

## Acceptance (runnable)
- CRUD at `/memories` with owner scoping, 404 / 422 / 409 (optimistic version), one audit
  event per write; a `private`/`secret` memory's body never appears in the audit log (only
  its length and hash)
- `provenance=verified` cannot be set through the API (reserved for evidence-backed
  memory, S6); `POST /memories/{id}/confirm` sets `user_confirmed` and confidence 1.0
- `GET /memories/search?q=` finds Chinese and English text: 3+ character terms through
  the FTS5 trigram index ranked by bm25, shorter terms by substring; several terms are ANDed;
  expired memories are excluded unless `include_expired=true`; editing or deleting a
  memory updates the index (tests)
- Export → import keeps memories and their search index working (test)
- The task module's audited-write helper is shared from `audit`, with no behaviour change
  (all existing tests pass unchanged)
- `uv run python scripts/verify/hub.py memory` exercises the above against the real Hub
  process and exits 0
- `uv run python -m tools.check` exits 0; ADR 0013 records the decisions
