## Goal
In a live walk on 2026-11-12, "把 Handshake 的邮件都标为已处理" got the answer "点确认后执行",
but no proposal was made, so the page showed no button. The prompt now says the call is the
only way to show the button. If an answer still promises 确认 without a proposal, the
assistant is reminded once to make it.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_chat.py -q`: a model that forgets the proposal is reminded
  once and the proposal arrives; a plain answer gets no extra turn.
- Live (real DeepSeek, real mail): `.evidence/T-0042/live.txt` shows both clear requests
  producing proposals (2 Handshake, 30 overdue) and a normal answer.
- `uv run python -m tools.check` exits 0.
