from the mailbox, which stays read-only. In the app, a handled mail now shows 已处理
instead of 未读, and the 未读 filter and count leave it out. The mailbox is not changed.

- `uv run python -m tools.check` exits 0.
- Live: the 邮件 page on the user's Hub shows 未读 reduced by the 44 handled mails.
