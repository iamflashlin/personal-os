## Goal
Phase 7. 开始学习 (T-0061/T-0062) needs the desktop agent connected, but until now the
agent only ran when started by hand. ADR 0043.

- `run-hub.ps1` (the supervisor the "PersonalOS Hub" task starts at logon) also starts
  the agent and restarts it after a crash, but only while `agent.enabled` exists in the
  data folder.
- An exit that a restart cannot fix (2 not paired, 3 token rejected, 4 replaced) is
  logged as "needs pairing" and not retried until `agent.enabled` is written again.
- `enable-agent.ps1`: one command for the user. It gets a pairing code from the running
  Hub, pairs the agent in the runtime copy (token in Credential Manager), and writes
  `agent.enabled`. `-Disable` removes it.
- `stop-hub.ps1` (used by update-hub.ps1) also stops the supervised agent, and only that.

## Acceptance (runnable)
- `uv run python scripts/verify/agent_always_on.py` exits 0, using the real scripts with a
  throwaway data folder, port and keyring name:
  - no agent runs without `agent.enabled`;
  - enable-agent.ps1 pairs and the agent comes online;
  - a killed agent is started again;
  - after a revoke the agent is not restarted and the log says "needs pairing";
  - enable-agent.ps1 again brings it back; `-Disable` stops it for good;
  - stop-hub.ps1 leaves no Hub or agent process of this checkout, and the always-on
    Hub keeps running.
- `uv run python -m tools.check` exits 0.
