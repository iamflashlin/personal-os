## Goal
After the history backfill the user has 357 mails, but 邮件 showed only the newest 100. Now
it lists every mail (up to the Hub's 1000 per request). Summaries are fetched in chunks of
200. The heading reads 「共 N 封，未读 M 封」. The filters 全部 / 未读 / 需处理 show counts;
需处理 means summary ok, action_needed, and not low value. The list stays newest first.

## Acceptance (runnable)
- `pnpm run test`: `filterMail` and `countMail` handle all, unread and action, and keep
  order. Low-value mail and mail without a summary never count as 需处理.
- `uv run python scripts/verify/web.py` exits 0. The heading counts all mail and unread
  mail, 需处理 shows only the Lab mail, and 未读 shows the three unread mails.
- `uv run python -m tools.check` exits 0.
