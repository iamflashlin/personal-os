## Goal
The third foundation before email and Canvas: one way to connect an outside source, sync
it in the background, and store what it returns without duplicates.
- An `integration` records an outside account: kind, the credential it uses, its sync
  interval, status, last success, last error and a sync cursor.
- Sync runs as a job (T-0010): at least once, retried, never two at once for one source.
- What a source returns is stored as `synced_item` rows: one per (integration, type,
  external id); a re-sync updates changed items and leaves the rest untouched.
- A first connector that needs no account authorisation: an ICS calendar feed. Canvas
  publishes one per student (HANDOFF §5's fallback), and its URL carries a private token,
  so the URL is kept as a credential (T-0011), never in SQLite or logs.

## Out of scope
- Email and the Canvas REST API (they need the user's choices and authorisation).
- Recurring events (RRULE), named time zones without tzdata, a web page.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_ics.py tests/hub/test_integrations.py -q` passes, covering:
  - the ICS parser: folded lines, escapes, UTC times, all-day dates, a TZID it cannot
    resolve (kept raw and flagged), events without UID skipped, non-calendar input refused;
  - create, list, get and delete an integration; an unknown kind or a missing credential
    is refused; the credential value is never in a response, table or log;
  - a sync stores new items, updates changed ones, leaves unchanged ones as they were
    (same version), and keeps no duplicates when run twice;
  - ETag/Last-Modified: an unchanged feed (304) writes no item;
  - a failing feed sets status `error` with a redacted message, and the job retries;
  - each integration has its own schedule, removed with it; with no integration
    nothing is scheduled; owner scoping; audit.
- `uv run python scripts/verify/hub.py integrations` exits 0 against the real Hub with a
  feed served locally and the feed URL in a throwaway Credential Manager entry.
- `uv run python -m tools.export_openapi --check` and `uv run python -m tools.check` exit 0.
