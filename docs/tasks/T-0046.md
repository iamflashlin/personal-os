## Goal
The user wants to see each data source and its status (scope, last sync, errors), never API details. The 连接 page starts with the user's six P0 data kinds: 学业, 日程, 邮件, 电脑活动, 文件和资料, 目标和经历. Each kind shows the connected sources, the last successful sync, a failure reason, and a stale flag after three missed sync intervals. Kinds that are not connected say so; kinds kept by hand in the Hub say so; kinds planned for later say 以后接入. This is web only and uses the integrations list the page already loads (fast lane, ADR 0035).

## Acceptance (runnable)
- `pnpm run test`: six kinds; ok vs stale; the error reason; none / local / later / never.
- `uv run python scripts/verify/web.py` exits 0: six kinds shown, PC says later, goals kept in the Hub, fits 390 px; screenshot `24-data-kinds-phone`.
