## Goal
Found in T-0071's review: the 今日 headline (briefing) counts only calendar events as 日程,
so on a day with a class added on 日程 it still says 「今天没有截止、日程或未读邮件」 while
今天的安排 right below lists the class. The headline should count today's agenda entries
(manual events, calendar events, homework blocks) the way 今天的安排 shows them, with
all-day items taken on their UTC date as the briefing already does.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_today.py -q`: a manual event today makes the headline
  mention 日程; a neighbouring day's all-day item does not.
- `uv run python scripts/verify/web.py` exits 0 with the headline and the list agreeing.
- `uv run python -m tools.check` exits 0.
