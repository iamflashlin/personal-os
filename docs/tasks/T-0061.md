## Goal
Phase 7 (real execution), vision direction 3 and the 14-system list's 「一键启动」 (the
user, 2026-11-22). ADR 0042.

One click on 开始学习 for a course should:
- say what to study next and why (the nearest exam's review map, weakest section first);
- open the right Canvas pages on the PC through the desktop agent (whitelisted
  `open_url`, each verified by its window title);
- remember the session, so the next start shows where the last one ended;
- after 学完了, skip what was just studied and offer the next thing.

The web page is T-0062. Running the agent with the always-on Hub is T-0063.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_study.py -q`:
  - the plan picks the nearest upcoming exam's first suggested section, with its reason,
    and lists open_url steps for the section's resource, the notes and the review sheet;
  - a course without an upcoming exam still gets a plan (notes only) and says so;
  - an unknown course is 404;
  - start with no agent connected is 503 and stores nothing;
  - start with an agent dispatches one action per step, at most once per key (a repeated
    key returns the same session and sends nothing);
  - the session shows each step's action status as the agent reports it;
  - finish needs the current version (409 when stale), and the next plan for that course
    skips the section just finished;
  - GET /study/next picks the course with the nearest exam.
- `uv run pytest tests/hub/test_actions.py -q` still passes after the dispatch refactor.
- `uv run python scripts/verify/study.py` exits 0: a real Hub and a real agent on this PC;
  a study start opens a served page whose title is checked, and the session reports
  succeeded.
- `uv run python -m tools.check` exits 0, including the migration drift check.
