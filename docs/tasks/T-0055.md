## Goal
Second page of the redesign the user asked for on 2026-11-12 (simple, nothing said twice,
regular aligned layout, every page).
- Shared header: only the page title. The explanatory subtitle and the date on every page
  go; 今日 is headed by the day itself.
- 今日: the Hub's one-sentence headline, then sections whose rows share three columns: when,
  what, from. The course is a short name (MATH 1A), not the Canvas title. A row has at most
  one tag and never one its section already says (no 未读 under 未读邮件, no 重要 under
  邮件里要你做的). What a mail asks for is one quiet line under its title.
- Empty sections are not drawn. A source that failed to sync is one line at the foot, not a
  red card at the top (the headline already says the data may be incomplete).
No Hub call changes. Mail whose deadline has passed still comes from the Hub; that is the
next card.

## Acceptance (runnable)
- `pnpm run test`: the short course name or sender for a row; one tag per row by section.
- `uv run python scripts/verify/web.py` exits 0: 今日 opens first, an empty day says so, the
  unread mail and the mail that needs action are listed, low-value mail is 次要.
- On a copy of the live DB (local screenshot): rows line up in three columns across all
  sections.
- `uv run python -m tools.check` exits 0.
