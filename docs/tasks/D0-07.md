## Goal
One command shows done / in progress / blocked / merged this week / rework, so progress
is measured by verified merges, not activity (HANDOFF §6.4, §7.5).

## Context / inputs
Task card frontmatter (`status`, `id`, `title`); `git log --first-parent main`
(squash merges). "Rework" = commits on main whose message starts with `fix:` and
references a card already `done`.

## Out of scope
Charts, web UI, cost tracking.

## Acceptance (runnable)
- `uv run python -m tools.report --today 2026-11-17` writes `docs/progress.md` and exits 0
- `uv run pytest tests/test_report.py -q` passes, covering: cards grouped by status, malformed frontmatter reported (not crashed), merges counted from a fixture git log, "this week" computed from `--today` (no wall-clock dependency)
- Running it twice with the same `--today` produces byte-identical output (compare `Get-FileHash docs/progress.md` before/after)
- `uv run python -m tools.check` exits 0
