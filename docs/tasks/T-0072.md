## Goal
14-system list #1 (第二大脑): memory should grow on its own from what the user does. When
the user clicks 学完了, the Hub stores one memory: 「11月22日 学完了 ENGL C1000「复习 S5 …」」
plus their note, kind experience, provenance raw (what happened, not a model's guess),
source `study:<session id>`. It shows on 记忆, where it can be corrected or deleted. No
grade goes into it. A failure to store it never undoes the finish. ADR 0042 (T-0072).

## Acceptance (runnable)
- `uv run pytest tests/hub/test_study.py -q`: finishing stores exactly one memory with
  that text, kind, provenance and source; a memory store failure still finishes the session.
- `uv run python scripts/verify/study.py` exits 0 with "the finished session is in 记忆".
- `uv run python -m tools.check` exits 0.
