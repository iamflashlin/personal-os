## Goal
The user wants a plain-language daily update in `docs/progress.md`. `tools.report`
regenerates the whole file, so anything written by hand is lost. Keep a 「今天」 block
at the top across regenerations.

## Acceptance (runnable)
- A block between `<!-- today:start -->` and `<!-- today:end -->` at the top of
  `docs/progress.md` survives `uv run python -m tools.report --today <date>` unchanged;
  `tests/test_report.py` covers it.
- With no such block, the report still renders, with an empty 「今天」 placeholder.
- Running twice with the same `--today` is still byte-identical.
- `uv run python -m tools.check` exits 0.
