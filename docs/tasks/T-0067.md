## Goal
14-system list #3: tasks and time. Knowing what is due is not enough; the user also
needs a time to do it. On 作业, each unsubmitted homework gets 排时间:
- the Hub suggests the earliest free slot (from the schedule's free time, inside the
  day window, at least 60 min by default) that ends before the homework is due;
- 排进日程 stores it as a schedule event (kind task, title 「写作业：<name>」); nothing is
  stored without the click;
- the row then shows 「已排：周二 19:00–20:00」, read back from the schedule, so a moved or
  deleted event is reflected.
No model call; the suggestion is computed.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_homework.py -q`:
  - the suggestion is the earliest free slot of at least N minutes before the due time,
    skipping busy time; none when no slot fits (said in plain words);
  - planning stores one task event; planning again returns the existing block (200), so at
    most one block per homework; the board shows it as planned; deleting the event, or
    the block passing, clears it;
  - submitted, unknown or other owners' homework cannot be planned (409 / 404).
- `uv run python scripts/verify/web.py` exits 0 with 排时间 → 排进日程 → 已排 on 作业 and the
  event visible on 日程 (screenshots).
- `uv run python -m tools.check` exits 0.
