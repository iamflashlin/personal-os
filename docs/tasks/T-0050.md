## Goal
The user said the pages look plain and stacked. Following common dashboard practice:
- a fixed left sidebar in groups (今天 / 学业 / 信息 / 系统), which on a phone becomes a sticky top strip that scrolls sideways;
- every page starts with its title and one line on what it is for;
- one set of design tokens (colours, radius, shadow) with a dark mode;
- colour only for meaning (status badges in soft fills; the primary colour only for actions and the current page);
- thin borders instead of heavy backgrounds;
- cards with distinct roles: the GPA headline as a stat card, course cards with a letter tile, warnings in a soft warn panel;
- 成绩 no longer says 按总分计算 or shows Canvas's unweighted group for a course computed from the syllabus.

No new files are fetched: system fonts only, no third-party requests (fast lane, ADR 0035).
