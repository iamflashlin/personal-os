## Goal
ADR 0036: the chat becomes an assistant that searches, reads and lists mail with tools,
answers from what it read, and proposes marking mail handled. The user confirms the
proposal in the chat, and can undo it.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_chat.py -q`:
  - search, read and cite; history is kept; the full body is sent;
  - sensitive mail is never sent;
  - a clear request becomes a proposal of open mail only, nothing changes before
    confirming, and confirming via /triage/handle works;
  - one model_call per step with `ref=""`, and the question is in no table;
  - MAX_STEPS stops the loop;
  - 503/502 mapping; budget and no key; the 422 cases;
  - tools: overdue, next 7 days, unknown refs and tools refused;
  - prompt rules.
- `uv run python scripts/verify/hub.py chat` exits 0. It uses the real Hub, fake IMAP and
  FakeProvider: an answer citing the Lab mail, 3 calls per question, a proposal that
  changes nothing until confirmed, the full text of the read mail sent, nothing of the
  code mail, and the question stored nowhere.
- `uv run python scripts/verify/web.py` exits 0: ask, answer, cited mails; a clear request
  shows a proposal; 确认 handles the mail; 撤销 restores it.
- `uv run python -m tools.check` exits 0.
- Live (real DeepSeek, real mail): `live-questions.txt` and `live-recheck.txt`.
