## Goal
The user stops reading mail.
- **连接 page:** a 「AI 邮件总结（DeepSeek）」 card with:
  - a masked API key field (`PUT /credentials/deepseek`) and 删除 key (`DELETE`);
  - whether a key is set;
  - 「本月已用 $x.xx / $10.00」, from `GET /models/usage`;
  - the blocked notice;
  - 「现在总结」 (`POST /summaries/run`).
- **最近邮件:** each mail shows its gist, a 「需处理」 badge with the action, and the
  deadline. Otherwise it shows 「未发送给 AI（可能含验证码或重置密码）」, 总结中… or 总结失败.
- **今日:**
  - mail entries carry their summary (`TodayEntry.summary`);
  - a new 「需要处理的邮件」 section lists up to 10 mails from the last 7 days that need
    action, read or not, deadline first (`TodayView.mail_actions`);
  - an `ai_notice` banner says 「本月 AI 预算已用完」, or that the key is missing or
    invalid.
- briefing reads summaries only through `summaries.service`.

## Out of scope
- Putting AI deadlines into 今天截止/接下来三天 or into tasks. That is a later card, once
  accuracy on real mail is known.
- Notifications. Retry buttons.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_today.py -q`:
  - mail entries carry their summary;
  - `mail_actions` holds only mail from the last 7 days that needs action, read mail
    included, deadline first, at most 10;
  - `ai_notice` follows `no_key` / `budget` / `key_rejected`;
  - an old client still validates, because the new fields have defaults;
  - another owner's summaries never appear.
- `pnpm run typecheck` and `pnpm run test` exit 0, with tests for:
  - the key form sends the key once, then clears it and never shows it;
  - spend is formatted from micro-USD;
  - each summary status renders its label;
  - React renders a summary that contains `<script>` as text.
- `uv run python scripts/verify/web.py` exits 0. It runs the real Hub with
  `POS_MODEL_PROVIDER=fake`, a fake IMAP server and Playwright, and checks:
  - entering a key fills the summaries on 最近邮件 and 今日;
  - the OTP mail shows 「未发送给 AI」;
  - 「需要处理的邮件」 lists the Canvas mail;
  - the key is not in the page HTML after saving.
- `uv run python -m tools.check` exits 0.
