## Goal
The user can open one page in the PC browser, see their goals, projects and tasks, add a
task, and mark a task done by confirming it. First thing in Personal OS the user can see
and use (user request, 2026-11-10). Desktop browser only; phone/PWA is S4.

## Context / inputs
HANDOFF §4.1 (apps/web: React + TypeScript + Vite), §3 item 5 (Evidence: "user
confirmation" is one kind), CLAUDE.md ("a task can never be marked done from model output
alone; it needs an Evidence row"), ADR 0009 (PATCH to `done` returns 409).

Marking done needs Evidence, so this card adds the smallest Evidence: one kind,
`user_confirmation`, written when a person confirms in the web UI. Its own Hub module
`evidence`; the task service writes the Evidence row and the status change in one
transaction. PATCH to `done` stays 409.

## Out of scope
PWA/offline/phone layout, auth and device tokens (S2/S8), editing or deleting from the UI,
other Evidence kinds (build/test output, commits: S6), TypeScript types generated from
openapi.json.

## Acceptance (runnable)
- `POST /tasks/{id}/complete` with `{"version": n, "note": "..."}` sets status `done`,
  creates exactly one Evidence row (kind `user_confirmation`) and one audit event, all in
  one transaction; stale version → 409; already done → 409; PATCH status `done` still 409
  (pytest)
- `uv run pytest tests/hub -q` passes, including the migration/model drift test
- `pnpm --dir apps/web build` produces `apps/web/dist`; the Hub serves it at `/` when it
  exists, and the API keeps working
- `uv run python scripts/verify/web.py` builds the UI, starts the real Hub on a free port
  with a temp data dir, seeds a goal and project over HTTP, then drives Microsoft Edge with
  Playwright: the seeded goal/project are listed, a task created through the form appears,
  confirming it shows it as done, and the Hub reports status `done` plus one Evidence row;
  screenshots of the page at each step; exits 0
- `uv run python -m tools.check` exits 0 (tsc and vitest include apps/web)
- New dependencies recorded in ADR 0011
- `docs/progress.md` "我能看到什么" lists the web UI once it is on main (tools/report.py showcase)
