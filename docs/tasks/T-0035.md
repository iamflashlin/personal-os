## Goal
The Hub side of 「帮我整理」 (ADR 0034):
- `GET /triage` returns the open count and the groups;
- `POST /triage/handle` applies a group or a set of mails, optionally saving the group's
  rule;
- `POST /triage/batches/{id}/undo`;
- `PUT /triage/items/{id}` marks one mail;
- `PATCH /triage/rules/{id}` switches a rule on or off.

The model-driven free-text commands are a later card.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_triage.py -q` covers:
  - every open mail is in exactly one group and the counts add up;
  - one sender's subdomains share a group;
  - a batch, then undo, then a second undo gives 409;
  - a saved rule covers a newly synced mail, and undo switches it off;
  - an unhandled mark beats a rule;
  - another owner's or unknown ids give 409/404;
  - saving a rule for a group without one gives 422, and an unknown group gives 409;
  - the audit holds counts, not mail text;
  - rule values are literal and small, invalid selectors are refused, and domain equality
    covers subdomains only;
  - course keys are extracted.
- `uv run python scripts/verify/hub.py triage` exits 0. It uses the real Hub, fake IMAP and
  FakeProvider:
  - the counts add up and the Handshake group has 6 mails;
  - handling the group takes 未处理 from 7 to 1, and 撤销 puts it back;
  - with the rule saved, a new Handshake mail is handled after a re-sync;
  - the mailbox's read flags are unchanged.
- `uv run python scripts/verify/hub.py roundtrip` still passes.
- `uv run python -m tools.check` exits 0, including the migration and model drift checks.
