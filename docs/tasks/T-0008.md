## Goal
VISION direction 3, HANDOFF S2 acceptance, on this PC:
- the real agent opens a test URL and a temp folder;
- verify() finds each window through pywinauto UIA, without needing the foreground;
- a screenshot of only our own page is saved;
- resending the same idempotency key executes once.

## Context / inputs
- ADR 0002: act on, close and capture only what the script created.
- HANDOFF §8.3: the foreground-window risk.
- Run the spikes listed in ADR 0014 (PrintWindow, default browser, VS Code, COM thread)
  first, and record the results in ADR 0016.
- Reuse `running_hub` from scripts/verify/hub.py.

## Out of scope
- Closing or focusing any window the script did not create.
- Sending keystrokes.
- VS Code screenshots: the Welcome page lists recent folders, and the account avatar shows.
- Installing VS Code or the `code` command.

- `uv run python scripts/verify/spike_printwindow.py` exits 0, and its result is recorded
  in ADR 0016 (or the D5 fallback is used).
- `uv run pytest tests/desktop_agent/test_windows_adapter.py -q` passes on Windows and
  skips elsewhere.
- `uv run python scripts/verify/desktop_agent.py` exits 0:
  - pairing succeeds and the agent is online;
  - open_url succeeds; a window title contains the unique marker, confirmed independently

  - the temp folder and the keyring entry are removed.

  blocked, not done.
