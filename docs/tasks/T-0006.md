## Goal
VISION direction 3 (数字世界的执行者), HANDOFF S2, the Hub half. The Hub:
- pairs a desktop agent with a one-time code;
- gives it a revocable token, storing only the token's hash;
- accepts its outbound WebSocket with heartbeat, and reports online or offline;
- dispatches whitelisted actions at most once per Idempotency-Key, storing each result
  and its evidence.

## Acceptance (runnable)
- `uv run pytest tests/contracts tests/hub/test_devices.py tests/hub/test_agent_ws.py tests/hub/test_actions.py -q`
  passes, covering:
  - pairing codes are one-time and expire; only the token's sha256 is stored; neither the
    token nor its hash appears in the audit log;
  - revoking closes a live socket with 4401; the handshake is refused (403) for a missing
    or revoked token, or for any Origin header;
  - heartbeat ack, 4408 on heartbeat timeout, 4409 when replaced; GET /agent/status
    reports online and offline;
  - POST /actions:
    - offline gives 503, writes no row, and does not consume the key;
    - a round trip stores the evidence;
    - a replay returns the same run with `Idempotent-Replayed` and sends no second frame;
    - the same key with a different body gives 422;
    - a disconnect mid-flight gives `lost`;
    - P2 or higher gives 403; an unsupported action gives 409;
  - one audit event per write.
- `uv run pytest tests/hub/test_module_boundaries.py tests/test_import_boundaries.py -q` passes:
  - a fake package proves that a desktop_agent → hub import fails lint;
  - devices and actions are in both hub contracts.
- `uv run python scripts/verify/hub.py agent` exits 0 against the real Hub, with a raw
  `websockets` client standing in for the agent:
  - pair, hello and welcome, heartbeat, status online;
  - one open_url frame is delivered; a replay delivers no second frame;
  - revoke gives 4401, then a reconnect gives HTTP 403;
  - the token does not appear in the bytes of hub.sqlite.
- `uv run python -m tools.export_openapi --check` exits 0.
- `uv run python -m tools.check` exits 0, and ADR 0014 becomes accepted.

## Errors & lessons

- lint-imports exits 1 without reporting any contract when the root packages share a
  regular (non-namespace) parent; the first version of the cross-app test passed its
  "must fail" cases for that wrong reason. The test now mirrors the namespace layout
  and asserts on the BROKEN/KEPT report text (docs/lessons.md).
- The same test failed only inside the gate: lint-imports' output encoding follows
  the inherited `PYTHONIOENCODING`. The subprocess now pins UTF-8 on both sides.
- TestClient cancels the app task as soon as a WebSocket session closes, which would
  skip the disconnect bookkeeping; the cleanup runs in a shielded cancel scope, which
  also covers a Hub shutdown with an agent connected.
