## Goal
ADR 0020's known limitation: an assignment deleted in Canvas, or an event removed from a
calendar feed, stayed stored forever and could show as 缺交. The user asked why it could
not be fixed. After a sync that saw the whole source, items it no longer returned are
removed. A sync that saw only part of the source (a skipped course, a 304, a failure)
removes nothing.

## Acceptance (runnable)
- `uv run pytest tests/hub/test_prune.py tests/hub/test_canvas.py tests/hub/test_integrations.py -q`:
  - a complete ICS sync removes an event that left the feed; a 304 removes nothing;
  - a complete Canvas sync removes a deleted assignment; a sync with a skipped course
    removes nothing; a failed sync removes nothing;
  - the sync counts and the audit event report `removed`.
- `uv run python scripts/verify/hub.py canvas` exits 0 and shows a removal.
- `uv run python -m tools.check` exits 0.
