## 愿景原文

我觉得我们先不要把 Personal OS 当成一个软件，而应该把它理解成：

一个真正了解你、能够主动管理生活、操控数字设备、帮助你完成实际工作的个人 AI 超级中枢。

我把整个产品概括为 8 大核心能力。先只讨论方向，不涉及技术和开发细节。

### Personal OS 的八大功能方向

1. **个人第二大脑**

   记住你的目标、经历、偏好、知识、项目进度和过去的决定。你不必反复解释背景，也不需要自己记住所有事情。

2. **主动规划与人生管理**

   帮你管理长期目标、日程、任务和习惯。知道你应该做什么、为什么做、什么时候做，并在偏离计划时帮助你重新回到主线。

3. **数字世界的执行者**

   这是最重要的功能之一。AI 能直接操控电脑、浏览器和兼容的软件，整理文件、查资料、填写表格、运行程序、完成多步骤工作。

   不只是告诉你怎么做，而是真的帮你做。

4. **个人能力增强器**

   帮你学习、编程、研究、写作、分析和创作。你可以与 AI 协作完成超出自己当前熟练程度的复杂工作，同时真正提高自己的能力。

5. **手机、电脑、耳机统一联动**

   手机成为 AI 统一入口，电脑负责复杂操作。你不需要记住打开哪个 App，只需要表达意图。

   比如通勤时戴着耳机复习英语、讨论项目、指挥电脑准备资料，到学校后无缝接续。

6. **感知环境与主动服务**

   系统根据时间、位置、日程、当前设备、使用行为和身体状态，判断你可能需要什么。

   不必每件事都等你主动提出。例如出门提醒、重要邮件跟进、任务提前准备、发现计划冲突。

7. **个人生活与自律系统**

   管理学习、游戏、睡眠、健身、兴趣、财务和休息。

   特别针对你的高启动门槛：帮助你快速开始，减少拖延和无意识娱乐，但也保留自主选择和正常休息。

8. **成长反馈与自我优化**

   自动记录真正的成果，用可视化进度、技能成长、成就奖励、每周报告提供正反馈。

   系统还会分析哪些工作流程可以优化，逐渐减少你需要亲自操作的步骤。

### 我心目中的最终体验

比如你早晨醒来，不需要自己逐个检查日历、Canvas、邮箱和任务软件。

Personal OS 已经整理好今天的重要事项。

你说一句“开始学习”，它就能替你打开相关资料、准备电脑环境，并接续上次的工作。

出门后，你戴上耳机，继续和 AI 讨论项目、复习知识。途中想到一个新功能，可以直接让 AI 记录、研究，甚至安排电脑上的开发任务。

到了晚上，它知道你完成了什么、有哪些事情还没推进，适时帮你调整计划，并向你展示真实的成长进度。

你负责目标、创造力和重要判断，系统负责记忆、组织、准备、执行和持续反馈。

### 还有一个需要区分的部分

我们之前讨论的多 Agent 自动化开发工厂，我认为应该是用来开发 Personal OS 的工具，而不是 Personal OS 本身的一项普通用户功能。

Personal OS 内部也可以使用多个 Agent 执行复杂任务，但两者的定位要分开。

另外，按你刚刚确定的范围，智能家居、全屋控制暂时完全排除。

### 我最想确认的一个方向

我认为这套产品的核心，不是“更智能的时间管理”，甚至也不只是“AI 帮你干活”。

而是：

**把一个人从记忆、规划、启动、执行到成长的整个过程连接起来，让 AI 成为个人能力的延伸。**

## 给开发者（Claude Code）的读法

- 每张产品任务卡在 `## Goal` 里写明它服务于上面哪个方向（1–8），以及它让“记忆 → 规划 →
  启动 → 执行 → 成长”这条链上的哪一环变得更顺。说不出来的卡不开工。
- 开发工厂（任务卡、`tools/check.py`、`tools/report.py`、审查流程）是开发工具，不算产品功能，
  不计入上面的八个方向。
- 智能家居、全屋控制不做。
